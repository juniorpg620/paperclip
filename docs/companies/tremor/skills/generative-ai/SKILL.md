# Generative Ai

Use when Tremor needs a generated draft or transformation from source material.

## Tremor Focus

- Turn source material into a useful first draft.
- Preserve enough provenance to trace claims back to inputs.
- Use generation to accelerate structure, not to bypass judgment.

## Workflow

1. Gather the source material and define the target shape.
2. Generate a draft with traceable inputs and a narrow scope.
3. Review the result against the source before it leaves the role boundary.

## Guardrails

- Do not merge synthesized content with verified fact without marking the boundary.
- Do not let a generated draft become the source of truth.
- Do not lose the original evidence trail.
