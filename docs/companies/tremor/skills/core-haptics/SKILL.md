# Core Haptics

Use when Tremor needs touch feedback that feels measured, intentional, and synchronized with play.

## Purpose

- Keep tactile feedback aligned with the player's action.
- Make haptic intensity a design choice, not an accident.
- Preserve the timing budget so the feel stays believable.

## When To Use

- Haptic cues for board state changes.
- Touch feedback that needs timing precision.
- Sensory design work for the dual-screen flow.

## When Not To Use

- Audio-only work.
- Non-interactive visual polish.
- Product decisions that belong in design or strategy.

## Inputs

- Desired tactile effect.
- Timing budget and trigger conditions.
- Real-device testing feedback.

## Outputs

- A haptic pattern or timing plan.
- Measured behavior on the device.
- A note explaining the perceptual tradeoff.

## Verification

- The feedback lands when the player expects it.
- Repeated runs feel consistent.
- The haptic path does not break the frame budget.
