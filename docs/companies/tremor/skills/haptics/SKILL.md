# Haptics

Use when Tremor needs tactile cues that reinforce action or state.

## Purpose

- Make touch feedback feel deliberate.
- Reinforce events without overwhelming the player.
- Keep haptics in sync with motion and audio.

## When To Use

- Button or state feedback.
- Player actions that need tactile confirmation.
- Sensory alignment work.

## When Not To Use

- Non-interactive visuals.
- Background system tasks.
- Strategy decisions.

## Inputs

- The event that should feel tactile.
- Intensity and timing goals.
- Device constraints.

## Outputs

- A haptic cue or rule.
- A timing note.
- A validation checklist.

## Verification

- The cue lands at the right moment.
- It feels consistent across runs.
- It does not fight the rest of the sensory stack.
