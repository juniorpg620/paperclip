# KPI Dashboard

## Core Metrics

- Round-trip latency
- State sync drift
- Acoustic pairing success
- Scan-to-mesh speed
- Visual fidelity
- Haptic jitter
- RAID resolution time
- Build pass rate

## Interpretation

- The Nervous System is healthy when sync is fast and stable.
- The Sensory Engine is healthy when pairing, scan, and simulation are accurate.
- The Experience layer is healthy when feel and visuals stay crisp.
- Operations is healthy when the roadmap stays clear and the build stays green.
