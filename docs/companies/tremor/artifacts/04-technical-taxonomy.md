# Technical Taxonomy

## How To Use

- Use this to map each role to a concrete technical moat.
- Use it as the interview surface for domain depth.
- If a task does not fit one of these domains, it needs a new explicit home.

- Local mesh networking
- Distributed state
- Security and integrity

## Domain III: Visual and Tactile Arts

## Domain IV: Operations and Governance

- RAID management

## Domain V: Neural Asset and IP Sovereignty

- Neural reconstruction

- IP sanitization

## Domain VI: Semantic Rule Ingestion and Logic Synthesis

- PDF rule parsing
- Reducer synthesis
- DSL architecture
- Deterministic validation

## Purpose

This taxonomy gives each role a concrete technical moat and a clear interview surface.
