# Roadmap

Use [Milestones](./04-milestones.md) for the branch-to-leaf breakdown of each phase.

## Branch Structure

- `Platform foundation`, `Sensory engine`, and `Launch readiness` are carried by `Tremor Flight Plan`.
- `Studio operations` runs in parallel through `Tremor Studio Ops`.
- Each branch resolves into three leaf goals so projects, issues, and milestones all point at the same execution spine.

## Phase 1

- Establish the authoritative state model.
- Land deterministic local mesh networking.
- Define the first vertical slice and regression harness.

## Phase 2

- Add board ingestion and sensory synchronization.
- Introduce the core haptic and visual language.
- Validate the system against the KPI dashboard.

## Phase 3

- Expand to more game formats.
- Harden AirPlay fallback and broader device support.
- Prepare the platform for publishing and reuse.

## Parallel Branch: Studio Operations

- Keep the device lab, onboarding flow, and approvals path healthy.
- Track budget and runway discipline against the active delivery slice.
- Maintain the recurring strategy, RAID, budget, lab-health, and regression routines.
