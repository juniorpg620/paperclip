# Roadmap and KPIs

## How To Use

- Use this as the execution spine for the first company phase.
- Tie every active project, issue, and hire back to one of these phases.
- If a new task does not move a KPI, question whether it belongs on the roadmap.

## Flight Plan

### Phase 1

- Establish the authoritative state model.
- Land deterministic local mesh networking.
- Define the first vertical slice and regression harness.

### Phase 2

- Add board ingestion and sensory synchronization.
- Introduce the core haptic and visual language.
- Validate the system against the KPI dashboard.

### Phase 3

- Expand to more game formats.
- Harden AirPlay fallback and broader device support.
- Prepare the platform for publishing and reuse.

## Milestone Tree

- Platform foundation
  - Authoritative state model
  - Local mesh transport
  - Rule ingestion and synthesis
- Sensory engine
  - Board ingestion and calibration
  - Timing, haptics, and audio
  - Render and simulation fidelity
- Launch readiness
  - Milestone control and RAID
  - Regression harness and QA automation
  - Release safety and dual-screen readiness
- Studio operations
  - Lab readiness and device health
  - Budget and runway discipline
  - Approvals and onboarding hygiene

## Key KPIs

- Round-trip latency
- State sync drift
- Acoustic pairing success
- Scan-to-mesh speed
- Visual fidelity
- Haptic jitter
- RAID resolution time
- Build pass rate
