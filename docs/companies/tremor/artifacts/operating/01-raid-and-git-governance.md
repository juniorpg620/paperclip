# RAID and Git Governance

## Governance Model

- The PM owns the RAID log.
- Risks are tracked before they become issues.
- Dependencies are explicit.
- Git must stay clean and reviewable.

## Practical Rules

- No broken main branch.
- No hidden blocker.
- No unowned critical path item.
- Every decision should be commented and traceable.
- Every key thread should end with a named owner and next check-in.
