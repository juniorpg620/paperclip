# Onboarding Guide

## Purpose

This guide is the first document for every Tremor hire.

## Core Expectations

- Know the mission.
- Know the squad you belong to.
- Know the technical moat you own.
- Use agents and tools to increase throughput.
- Keep work moving and leave no task without a comment.

## Day 1

- Read the mission, roster, and your role brief.
- Open the skill pack that maps to your role.
- Confirm your squad, manager, and first delivery owner.
- Review the KPI dashboard so you know what gets measured.
- Add a comment on your first active task with your plan and blocker check.

## Week 1

- Ship one small, real contribution in your lane.
- Use the issue tracker for every meaningful task and dependency.
- Keep one active RAID item if you see a risk.
- Ask for review early when a decision changes architecture, spend, or scope.

## Global Initialization

- Install the core agentic suite.
- Load role-specific tools and skills.
- Learn the taxonomy and KPI dashboard.
- Review the operating cabinets before you ask for help.

## Squad Structure

- Squad A: Nervous System
- Squad B: Sensory Engine
- Squad C: Fidelity and Quality
