# Expanded Agentic Skills Matrix

This expands the short skills note into a role-by-role matrix aligned to the source conversation.

## Role to Agentic Pattern

| Role ID | Agentic Pattern | What It Should Automate |
|---|---|---|
| Founder / Engineering Lead | Strategic synthesis | Prior-art research, architecture notes, technical appendix drafting |
| Co-Engineering Lead A / Platform and Networking Lead | Platform critique | State sync review, network tradeoff analysis, architecture alignment |
| Co-Engineering Lead B / Simulation and Sensory Lead | Simulation critique | Determinism checks, haptic/audio experimentation, feel validation |
| Technical Program Manager | RAID orchestration | Risk tracking, status collection, blocker escalation |
| Studio Operations and Logistics | Operational bookkeeping | Hardware inventory, checkout, lab readiness |
| Systems and Network Engineer | State machine review | Network edge cases, fallback tuning, packet-loss analysis |
| Platform and DevSecOps Engineer | DevSecOps automation | CI/CD checks, secret hygiene, deployment guardrails |
| DSP and Audio Engineer | Signal synthesis | Audio protocol experiments, FFT analysis, haptic timing |
| Computer Vision and AR Engineer | Synthetic perception | Labeled data generation, model prep, AR calibration |
| GenAI Architect | Multi-modal RAG | Search, rule extraction, asset skinning, content synthesis |
| Simulation Engineer | Chaos simulation | Parallel playthroughs, bug surfacing, stress loops |
| Technical Artist | Neural rendering | Shader iteration, material generation, synthetic datasets |
| Lead Product Designer | Sensory translation | Haptic waveform drafting, interaction patterns, onboarding polish |
| Tools QA Engineer | Validation harnesses | Latency tests, thermal tests, and stress orchestration |
| SDET Engineer | Test generation | Regression creation, HIL automation, self-healing tests |

## Shared Operating Rules

- Agents should draft boilerplate, tests, and first-pass docs.
- Humans must verify all merged logic and domain claims.
- Every agentic loop should be traceable in the permanent research record.
- Lead roles own critique and final judgment, not just generation.

## Role Families

- Leadership: synthesis and governance.
- Infrastructure: safety, transport, and state integrity.
- Sensory: search, vision, audio, and generative assets.
- Fidelity: haptics, rendering, testing, and simulation.
