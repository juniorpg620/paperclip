# HEARTBEAT.md -- Admin and Operations Heartbeat Checklist

## 1. Review Admin Work

- Check hiring, contracting, and operations tasks.
- Prioritize anything that unblocks the technical team.
- Keep track of items that are waiting on signatures or decisions.

## 2. Keep Records Current

- Update status when an admin task changes.
- Make sure the founder knows about any operational blocker.
- Flag anything that is overdue or at risk.

## 3. Coordinate

- Ask the founder when a decision is required.
- Work with program management when a process needs structure.
- Leave a comment with the current status and next action.
