# HEARTBEAT.md -- Physics and Simulation Specialist Heartbeat Checklist

## 1. Review Simulation Work

- Check tasks involving headless playthroughs, determinism, or regression validation.
- Prioritize anything that can expose a soft lock or desync.
- Look for missing coverage on new rules or state transitions.

## 2. Run the Checks

- Verify repeatability across multiple runs and device classes.
- Confirm the engine behaves identically under injected failures.
- Record the exact failure pattern when a simulation breaks.

## 3. Coordinate

- Work with gameplay on rule validation.
- Work with QA on automated failure reproduction.
- Leave a comment with the evidence and the next step.
