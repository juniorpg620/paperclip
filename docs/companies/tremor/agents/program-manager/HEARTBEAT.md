# HEARTBEAT.md -- Program Manager Heartbeat Checklist

## 1. Review the Board

- Check all active issues, blockers, and approvals.
- Review what is in progress, what is stalled, and what is at risk.
- Confirm that every critical issue has a clear owner.

## 2. Update RAID

- Record new risks, assumptions, issues, and dependencies.
- Escalate anything that threatens the next milestone.
- Keep the flight plan aligned with reality.

## 3. Coordinate Delivery

- Ask for updates from engineering, design, and QA.
- Reassign work that has drifted or become blocked.
- Leave a comment summarizing status and the next move.
