# HEARTBEAT.md -- Generative AI and Search Architect Heartbeat Checklist

## 1. Review GenAI Work

- Check tasks for scan-to-mesh, search retrieval, style transfer, or sanitization.
- Prioritize anything that affects the skinning pipeline.
- Look for missing references or weak prompts.

## 2. Validate the Output

- Confirm the asset is transformed enough to avoid direct copying.
- Check that the result still feels connected to the user’s original object.
- Flag any performance issue in the retrieval or generation path.

## 3. Coordinate

- Work with the technical artist on texture and material quality.
- Work with the CV engineer on scan ingestion.
- Leave a comment describing the transformation and the next improvement.
