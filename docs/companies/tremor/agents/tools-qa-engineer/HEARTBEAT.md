# HEARTBEAT.md -- Tools and QA Engineer Heartbeat Checklist

## 1. Review Test Work

- Check tasks involving automation, latency checks, or failure injection.
- Prioritize regressions that affect sync, pairing, or fidelity.
- Watch for missing coverage on recently changed behavior.

## 2. Run the Checks

- Validate the current build against known failure modes.
- Reproduce issues with the smallest possible setup.
- Record the result in a way engineers can act on immediately.

## 3. Coordinate

- Work with engineering on any reproducible defect.
- Work with the program manager when a risk needs escalation.
- Leave a comment with the evidence and the recommended next step.
