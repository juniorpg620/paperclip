# HEARTBEAT.md -- Computer Vision and AR Engineer Heartbeat Checklist

## 1. Review Vision Work

- Check tasks for board scanning, model training, or AR mapping.
- Prioritize anything that affects state ingestion accuracy.
- Look for missing training data or unclear labeling rules.

## 2. Validate Recognition

- Inspect confidence thresholds and misclassification patterns.
- Check whether the current model holds up under poor lighting and clutter.
- Flag any regression that needs a better dataset or fallback UI.

## 3. Coordinate

- Work with the technical artist on synthetic generation.
- Work with the product designer on confidence UX and scan feedback.
- Leave a comment with the result and what still needs work.
