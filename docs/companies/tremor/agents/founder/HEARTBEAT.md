# HEARTBEAT.md -- Founder Heartbeat Checklist

Run this on every heartbeat.

## 1. Check the Company

- Review the top company goal.
- Check budget, runway, and any critical blockers.
- Read the latest updates on the highest-priority issues.

## 2. Review Direct Reports

- Inspect the status of engineering, product, and operations leads.
- Look for blocked work, stalled decisions, or missing ownership.
- Push unclear work back down to the right owner.

## 3. Make Decisions

- Approve or reject proposals that change scope, budget, or architecture.
- Decide what gets stopped if priorities conflict.
- Escalate only when a decision truly cannot be made lower in the org.

## 4. Keep Momentum

- Add a comment on the task before exiting.
- Delegate the next concrete step.
- Leave no critical issue without an owner.
